Whick 뮤직서버 — Docker 재실행

재생·연결 이상 시 고객 PC에서 Docker 컨테이너만 다시 시작합니다. (재설치 아님)

① 파일 받기

아래 첨부 whick-docker-restart.sh 를 다운로드 폴더에 저장하세요.

② 실행

  1. 다운로드 폴더에서 우클릭 → 터미널에서 열기
  2. 한 줄 입력:
    chmod +x whick-docker-restart.sh && ./whick-docker-restart.sh
  3. 「OK 뮤직서버(audio) 정상」이 나오면 완료

설치 경로: ~/whick-3product · 관제에서 원격 재시작을 요청받은 경우에도 동일하게 실행 가능
