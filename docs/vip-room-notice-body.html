② 설치

  1. setup.deb 더블클릭 → 「신뢰함」→ 설치 → 비밀번호
  2. 「설치됨」이 나오면 — 검은 창(터미널)이 자동으로 열리거나, 아래 ③
  3. 검은 창이 안 열리면 → 왼쪽 아래 9점(앱) → 「Whick 설치」 클릭
  4. 검은 창에서 비밀번호(sudo) 입력 → 「완료」까지 자동

「설치됨」은 설치 프로그램만 깔린 상태입니다. Whick 본체는 ③ 검은 창에서 이어집니다.
