USB 설치 — 고객 안내 (유선)
USB Install Guide (Wired)
==========================

스마트폰만으로 설치합니다. (모니터·키보드 불필요)
Install with your smartphone only. (No monitor/keyboard needed)

[준비 / Prep]
  뮤직서버용 미니PC RAM 8GB 이상 · SSD 64GB 이상
  Mini PC for music server: RAM 8GB+ · SSD 64GB+
  스마트폰으로 Wi-Fi 접속 후 remote.whick.org를 열어 주세요.
  On your phone, join Wi-Fi and open remote.whick.org.

[1. USB 만들기 / Create USB]
  VIP Room에서 USB설치용-유선.zip 받기 → 압축 풀기 → make-usb.bat 실행
  Download USB설치용-유선.zip from VIP Room → unzip → run make-usb.bat

[2. 유선 설치 (미니PC + 스마트폰) / Wired install]
  ① 미니PC에 유선 LAN을 연결합니다. (필수)
     Connect wired LAN to the mini PC. (Required)
  ② 설치 USB를 미니PC에 꽂고, 전원을 켭니다.
     Insert the install USB into the mini PC and power it on.
  ③ 미니PC 초기 설치가 진행되고 Whick 서버에 연결될 때까지 수분 걸립니다.
     Initial setup runs and connects to Whick — this can take several minutes.
  ④ 미니PC IP와 whick.org 로그인 IP가 같으면(Lv3+) 설치 안내 메일이 발송됩니다.
     When mini PC IP matches your whick.org login IP (Lv3+), an install guide email is sent.
  ⑤ 설치 도우미의 안내에 따라 진행합니다.
     Follow the on-screen install helper.
  ⑥ 이후 설치는 원격으로 중앙관제센터 AI가 진행합니다.
     Remaining install steps are done remotely by Whick Control Center AI.
  ⑦ 설치 도우미를 닫지 마세요. 설치 과정에서 장애가 생기면 해결 방법이 표시됩니다.
     Do not close the helper. If something fails, fix steps will appear.

문의 / Contact: whick.org VIP Room
