Whick 뮤직서버 — USB 설치

미니PC와 스마트폰으로 설치가 진행되며 설치 USB는 Windows PC로 제작합니다.
공유기 Wi-Fi 접속 후 whick.org 로그인 · Lv3+ 필수.

아래 유선 / 무선 탭에서 설치 방법과 설치 파일을 확인하세요. (유선·무선 USB는 각각 필요한 구성만 포함합니다.)

설치 안내 — 고유 접속 주소

유선·무선 모두 whick.setup이 아닌, 회원별 고유 접속 주소(whick.org/page/계정)에서 설치 진행을 확인합니다.

  1. 결제 완료 메일 또는 계정정보에서 고유 접속 주소를 북마크합니다.
  2. 미니PC USB 부팅 후, 스마트폰을 같은 공유기 Wi-Fi에 연결하고 whick.org에 로그인합니다.
  3. 고유 접속 주소에서 설치 단계·진행률·재부팅 안내를 확인합니다.
  4. 설치 완료 후 같은 흐름에서 리모컨으로 이관됩니다.

무선 USB — Wi-Fi 입력 · 맞춤 파일

  1. 아래 무선 탭에서 공유기 Wi-Fi SSID·비밀번호를 입력하고 «맞춤 USB 만들기».
  2. 생성된 zip으로 USB 제작 → 미니PC 부팅 (미니PC가 사전 입력 Wi-Fi에 자동 연결).
  3. 스마트폰은 고유 접속 주소에서 설치 안내를 따릅니다 (Whick-Setup AP·whick.setup 불필요).

설치 완료 후 리모컨에서는 공유기 Wi-Fi 직접과 중앙관제 터널 연결 방식을 설정에서 자유롭게 전환할 수 있습니다.
