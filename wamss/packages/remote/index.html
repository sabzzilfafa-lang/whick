연결 상태 불러오는 중…

뮤직서버에 연결된 저장소의 음원을 스캔하여 라이브러리에 추가합니다. 검수로봇이 음원 품질을 자동으로 확인하고 분류로봇이 장르·분위기별로 분류합니다. 추가된 곡은 음량 정규화가 백그라운드에서 1곡씩 진행됩니다.

🤖 음원검수로봇 기준
선택한 형식 중 하나라도 기준을 통과하면 등록합니다. 모두 끄면 검수 없이 전체 허용합니다.

🔊 음량정규화(유튜브-14LUFS)
곡마다 체감 음량을 맞춥니다. 원본 파일은 그대로 두고, 재생 시에만 게인을 적용합니다.
⚠️ 미니PC CPU 안내 — 정규화는 곡을 분석할 때 CPU를 사용합니다. 재생에 영향이 없도록 백그라운드에서 1곡씩만 처리하며, 재생 중·재생이 끝난 뒤 5분 동안은 자동으로 멈춥니다. 수백 곡을 한꺼번에 추가하면 완료까지 시간이 걸릴 수 있습니다.
라이브러리 추가 후 자동 정규화
정규화 상태 불러오는 중…
파일 탐색기=실제 음원(부모), 라이브러리=바로가기(목록). 파일 삭제는 탐색기에서만, 목록 제거는 라이브러리에서.

뮤직서버의 음원을 뮤직서버 → CPU전처리 → DAC → AMP → Speaker로 출력합니다 · CPU전처리(CamillaDSP)에서 DAC가 하던 음원 가공을 미리 수행 · 외부에서는 스마트폰으로 뮤직서버 음원을 감상할 수 있습니다
